# 🏢 AI Office 3D — Realtime Autonomous AI Studio

> An immersive, stylized 3D virtual workplace powered by **Three.js**, **React 19**, and **WebGL**, simulating a team of autonomous AI agents collaborating, writing code, analyzing papers, rendering 3D shaders, and monitoring cloud clusters in real time.

---

## 🌟 Key Features

* **Stylized 3D Animated Avatars:**
  * Animated humanoid AI agents with procedural breathing, typing oscillations, and bobbing holographic status gems.
  * Interactive raycasting: Click any workstation or agent to swoop in with a cinematic camera damping glide.
* **Realtime Agent Simulation & Live Screens:**
  * **Nova Rivera (Lead AI Engineer):** Compiles Wasm SIMD token streamer kernels and writes TypeScript.
  * **Pixel Maya (3D UI Designer):** Renders frosted glass PBR shaders and CSS variables.
  * **Dr. Atlas Vance (Cognitive Research Lead):** Ingests and synthesizes arXiv multimodal reasoning papers.
  * **Cipher-9 (DevOps Sentinel):** Monitors Kubernetes cluster telemetry and firewall radar sweeps.
  * **Aria Chen (Product Orchestrator):** Manages multi-agent roadmaps and sprint milestones.
  * **Dynamic Canvas Monitors:** Computer monitors on desks physically render animated code, security sweeps, and graphs in 3D.
* **Central Boardroom "All-Hands Sprint":**
  * One-click All-Hands trigger: Agents physically get up from their desks, walk over to the central oval frosted glass table, and collaborate with real-time consensus ticker dialogues!
* **Zero-Dependency Web Audio Soundscape:**
  * Procedurally synthesized typing clicks, conference chimes, and milestone completion dings via native Web Audio API.
* **Cinematic Camera System & Day/Night Cycles:**
  * Quick presets for Isometric Overview, Dev Bay, Design Studio, Research Lab, Security Ops, Boardroom, and Architectural Floorplan.
  * Cyberpunk Neon Night mode vs Clean Daylight studio mode.
* **Interactive Mission Dispatcher:**
  * Prompt any agent with new instructions; watch them dynamically accept the mission, update their thoughts, and execute progress.

## 🚀 Quick Start

### 1. Installation
```bash
npm install
```

### 2. Development Server
```bash
npm run dev
```

### 3. Production Build
```bash
npm run build
```

---

## 🛠️ Architecture & Tech Stack

* **3D Engine:** Three.js (Procedural geometries, PBR frosted glass shaders, dynamic canvas textures, directional shadows).
* **UI & HUD Framework:** React 19 + Lucide Icons + Canvas-Confetti.
* **Audio Synthesis:** Native Web Audio API (zero audio file assets required).
* **Styling:** Custom 60-30-10 Design System with glassmorphic backdrop filters and WCAG AAA compliance.
* **Bundler:** Vite 8.
